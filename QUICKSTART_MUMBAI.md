# ⚡ Quick Start - Polygon Mumbai Testnet

**Get started in 5 minutes with FREE gas!**

## ✅ Prerequisites

- [ ] MetaMask installed
- [ ] Have internet connection

## 🚀 Quick Setup (5 minutes)

### 1️⃣ Add Mumbai Network to MetaMask (30 seconds)

**Visit:** https://chainlist.org/chain/80001

1. Click "Connect Wallet"
2. Click "Add to MetaMask"
3. Done! ✅

### 2️⃣ Get Free Test MATIC (1 minute)

**Visit:** https://faucet.polygon.technology/

1. Select "Mumbai"
2. Paste your wallet address
3. Click "Submit"
4. Wait 30 seconds → Get **0.5 MATIC FREE** ✅

### 3️⃣ Start App (1 minute)

```bash
npm install
npm run dev
```

Open: http://localhost:3000

### 4️⃣ Connect Wallet & Test (2 minutes)

1. Click "Connect Wallet"
2. See "🧪 Mumbai Testnet" badge
3. See "Gas fees: FREE" indicator bottom-left
4. Create an event → Gas fee: **~$0.00** ✅
